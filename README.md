# React Components

A growing collection of reusable React components, built while practicing core React concepts like props, state, hooks, and composition.

## Tech Stack
- React
- Vite
- Oxlint

## Purpose
This repo is a sandbox for building and experimenting with individual React components in isolation — useful for practicing patterns before using them in bigger projects (like my [portfolio](https://github.com/INAYAT-ULLAH67/Portfolio)).

## Getting Started

```bash
git clone https://github.com/INAYAT-ULLAH67/ReactComponents.git
cd ReactComponents
npm install
npm run dev
```
